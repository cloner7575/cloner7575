🧭 رویکرد من در Backend Engineering

وقتی یک feature backend می‌سازم، فقط به این فکر نمی‌کنم که endpoint جواب 200 بدهد.

معمولاً این سؤال‌ها برایم مهم‌اند:

اگر request دوبار ارسال شود چه می‌شود؟
اگر callback دوبار برسد چه می‌شود؟
اگر Celery worker وسط task crash کند چه می‌شود؟
اگر Provider خارجی timeout بدهد چه می‌شود؟
اگر دو User هم‌زمان یک Resource محدود را بخواهند چه می‌شود؟
اگر DB transaction rollback شود چه می‌شود؟
برای debug کردن production چه چیزی باید log شود؟
